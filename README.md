# 10th Maths Student Evaluation Worksheet Generator (PWA)

## Deploy to GitHub Pages (with Address Bar PWA Install)
1. Create a new public repository on GitHub (e.g. `10th-maths-worksheet`).
2. Upload all files from this ZIP (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon.svg`) to the root of the `main` branch.
3. Go to **Settings -> Pages**, choose **Source: Deploy from a branch**, select `main` / `/ (root)`, and click **Save**.
4. Open your live `https://<username>.github.io/10th-maths-worksheet/` URL on Desktop, Mobile, or Smart Board — the **Install App** icon will appear in the browser address bar and the **Install App** button in the top bar will work directly.
